
# 🎬 Netflix Clone — Netflix India Homepage

A Netflix-inspired homepage built using HTML, CSS, and JavaScript. This project recreates the look and feel of Netflix India for learning and educational purposes.

## ✨ Features

- 🎥 Netflix-inspired homepage design
- 🖼️ Background image with dark overlay
- 🔴 Navigation bar with logo, language button, and sign-in button
- 📺 Hero section with email input and Get Started button
- 🍿 Trending Now movie poster section
- 📱 Streaming feature sections
- ❓ Frequently Asked Questions section
- 🎨 Custom curved blue-and-red decorative border
- 📱 Responsive styling
- ⚡ JavaScript interactions and basic email validation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Check that all image and video paths are correct.
4. Open `index.html` in your browser.
5. Alternatively, use the Live Server extension in VS Code.

## 🎯 Project Objective

The goal of this project is to learn frontend web development, practice HTML page structure, apply CSS styling, and implement interactive features using JavaScript.
